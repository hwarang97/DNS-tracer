# DNS 이름 풀이 추적기 프로젝트 계획서

## 프로젝트 개요

도메인을 입력하면 루트 DNS 서버부터 권한 DNS 서버까지 직접 질의해 최종 IPv4 주소를 찾는 과정을 보여 주는 Python CLI 학습 도구다.

프로젝트는 `dnspython`으로 직접 DNS 질의를 수행하고, Windows 일반 이름 조회 결과도 함께 보여 준다. DNS 서버나 재귀 DNS 리졸버를 새로 구현하지 않는다.

## 완료한 단계

### 1단계: 루트 DNS 서버에 직접 질의

- 루트 DNS 서버에 A 레코드 질의를 보냈다.
- 루트 서버가 알려 준 다음 DNS 서버 정보를 확인했다.

### 2단계: TLD와 권한 DNS 서버 추적

- 루트 서버 응답을 바탕으로 다음 DNS 서버를 자동으로 선택했다.
- TLD DNS 서버와 권한 DNS 서버까지 반복 질의했다.
- 최종 A 레코드의 IPv4와 각 질의 서버를 출력했다.

### 3단계: Windows DNS 캐시 TTL과 hosts 파일 확인

- `socket.getaddrinfo()`를 이용해 Windows 일반 이름 조회 함수를 추가했다.
- 직접 DNS 추적 결과와 Windows 일반 조회 결과를 함께 출력했다.
- `ipconfig /displaydns`와 `ipconfig /flushdns`로 Windows DNS 캐시와 TTL 감소를 확인했다.
- `hosts` 파일 설정이 Windows 일반 조회에는 적용되고 직접 DNS 추적에는 적용되지 않음을 확인했다.

## 최종 동작

```text
도메인 입력
→ 루트 DNS 서버 질의
→ TLD DNS 서버 질의
→ 권한 DNS 서버 질의
→ 최종 IPv4 출력

같은 도메인의 Windows 일반 조회
→ Windows DNS 캐시와 hosts 파일을 반영한 IPv4 출력
```

## 범위

### 포함

- A 레코드(IPv4) 직접 DNS 추적
- 직접 DNS 추적 경로 출력
- Windows 일반 이름 조회 결과 출력
- Windows DNS 캐시 TTL 및 hosts 파일 실습

### 제외

- AAAA, CNAME 등 A 레코드 이외의 조회
- DNS 캐시 또는 재귀 DNS 리졸버 구현
- 프로그램을 통한 hosts 파일 자동 수정
- 오류 처리 확장과 별도 문서화 단계

## 최종 산출물

- DNS 이름 풀이 추적 CLI 프로그램
- 직접 DNS 추적과 Windows 일반 조회의 비교 결과
- Windows DNS 캐시 TTL 및 hosts 파일 실습 결과

프로젝트는 3단계 완료 상태에서 마무리한다.
