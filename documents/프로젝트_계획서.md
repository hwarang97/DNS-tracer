# DNS 이름 풀이 추적기 프로젝트 계획서

## 프로젝트 개요

도메인을 입력하면 루트 DNS 서버부터 권한 DNS 서버까지 직접 질의하여, 최종 IP 주소를 찾는 과정을 단계별로 보여 주는 CLI 기반 학습 도구를 만든다.

프로젝트는 JavaScript와 Node.js를 사용한다. 초기에는 DNS 서버를 새로 만들지 않고, 기존 DNS 서버에 질의하는 추적 클라이언트를 구현한다.

## 단계별 계획

### 1단계: 루트 DNS 서버에 직접 질의

- IANA root hints 정보를 준비한다.
- 도메인 입력 기능을 만든다.
- 루트 DNS 서버에 질의해 TLD DNS 서버 정보를 출력한다.

### 2단계: TLD와 권한 DNS 서버 추적

- 루트 서버 응답을 바탕으로 TLD DNS 서버에 질의한다.
- TLD 서버 응답에서 권한 DNS 서버 정보를 찾는다.
- 각 단계의 질의 대상과 응답을 기록한다.

### 3단계: 최종 IP 주소 조회

- 권한 DNS 서버에 A 레코드를 질의한다.
- 최종 IPv4 주소를 출력한다.
- AAAA 레코드와 CNAME 조회를 순차적으로 추가한다.

### 4단계: 추적 결과 정리

- 다음 정보를 순서대로 출력한다.

```text
질의 단계
질의한 DNS 서버
질의한 도메인과 레코드 종류
서버 응답
다음에 질의할 DNS 서버
최종 IP 주소
```

### 5단계: 일반 DNS 조회와 비교

- 시스템 기본 DNS 리졸버를 이용한 일반 조회 기능을 추가한다.
- 직접 추적 결과와 일반 조회 결과를 나란히 비교한다.

### 6단계: 캐시, TTL, hosts 파일 실습

- DNS 응답의 TTL을 표시한다.
- 반복 조회 결과를 기록해 캐시와 TTL을 관찰한다.
- `hosts` 파일을 활용한 로컬 이름 해석 실습을 추가한다.

### 7단계: 오류 처리와 문서화

- 존재하지 않는 도메인과 DNS 서버 응답 실패를 처리한다.
- 각 실습 과정, 관찰 결과, 배운 내용을 README에 정리한다.

## 구현 방향

- 1차 결과물은 명령줄(CLI) 프로그램으로 만든다.
- 루트·TLD·권한 DNS 서버의 위임 경로를 직접 따라간다.
- 추적 기능은 공용 재귀 리졸버의 실제 내부 기록을 보는 기능이 아니라, DNS 권한 조회 경로를 학습용으로 재현하는 기능으로 정의한다.
- 직접 질의에 필요한 루트 서버 정보는 IANA가 제공하는 root hints를 사용한다.
