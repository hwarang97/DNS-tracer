# 2단계 구현서: DNS 조회 자동화와 함수 분리

## 1. 현재 진행 범위

2단계에서는 루트 DNS 서버 응답을 바탕으로 다음 DNS 서버에 질의하는 과정을 자동화한다.

현재 구현은 `www.example.com.`을 대상으로 루트 DNS 서버부터 질의를 반복하고, 각 단계의 서버 IP와 최종 IPv4를 기록한 목록을 반환한다. 최신 커밋 `10969f7`에서는 DNS 조회와 IP 추출 로직을 함수로 만들고 `dns_trace.py`로 이동했다.

현재 범위는 A 레코드(IPv4) 조회이다. CNAME을 따라가 최종 IP를 찾는 기능은 포함하지 않는다.

## 2. 파일 구성

```text
main.py       # 조회할 도메인과 루트 DNS 서버 IP를 지정하고 결과를 출력
dns_trace.py  # DNS 질의, IPv4 추출, 반복 조회 함수
```

`main.py`는 `dns_trace.trace_domain()`으로 DNS 조회 경로를 얻고, `dns_trace.print_trace()`로 결과를 출력한다.

```python
trace = dns_trace.trace_domain(domain, root_sever_ip)
dns_trace.print_trace(domain, trace)
```

## 3. `query_dns()` 함수

```python
def query_dns(domain: str, dns_server_ip: str) -> dns.message.Message:
```

함수의 역할은 다음과 같다.

1. 전달받은 도메인으로 A 레코드 DNS 요청 메시지를 생성한다.
2. 전달받은 DNS 서버 IP에 UDP로 질의한다.
3. 응답에 `TC` 플래그가 있으면 TCP로 같은 요청을 다시 보낸다.
4. DNS 응답 객체를 반환한다.

호출하는 쪽은 UDP와 TCP 전환 규칙을 알 필요 없이 도메인과 서버 IP만 전달한다.

## 4. `extract_ip()` 함수

```python
def extract_ip(response: dns.message.Message) -> list[str]:
```

이 함수는 응답에서 A 레코드에 해당하는 값을 추출해 문자열 목록으로 반환한다.

- `ANSWER`가 있으면, 그 안에서 A 레코드만 찾아 모든 값을 목록에 담는다.
- `ANSWER`가 비어 있으면, `ADDITIONAL`에서 A 레코드 하나를 찾아 목록에 담는다.

현재 구현은 `ADDITIONAL`에서 발견한 첫 번째 A 레코드를 다음 DNS 서버 후보로 사용한다.

## 5. `trace_domain()` 함수

```python
def trace_domain(domain: str, root_server_ip: str) -> list[dict[str, str]]:
```

이 함수는 현재 질의 대상 서버 IP를 `server_ip`에 저장하고, `while True`로 DNS 질의를 반복한다. 반환값은 최종 IP만이 아니라 각 DNS 질의 단계를 기록한 `traces` 목록이다.

1. `query_dns()`로 현재 DNS 서버에 질의한다.
2. 현재 질의 단계를 기록할 `current` 딕셔너리를 만든다.
3. `response.rcode()`가 `dns.rcode.NOERROR`가 아니면 오류를 발생시킨다.
4. `ANSWER`가 있으면 `final_ips`에 최종 IPv4 목록을 저장하고, `current`를 `traces`에 추가한 뒤 반환한다.
5. `ANSWER`가 비어 있으면 `extract_ip()`으로 얻은 첫 번째 IP를 다음 질의 대상 서버 IP로 설정하고, `current`를 `traces`에 추가한다.

이로써 `main.py`에 고정되어 있던 루트 → 다음 DNS 서버 → 다음 DNS 서버의 질의 순서를 함수 내부의 반복 구조로 바꿨다.

각 단계는 아래와 같이 같은 키를 사용한다.

```python
{
    "server_ip": "현재 질의한 DNS 서버 IP",
    "next_server_ip": "다음 DNS 서버 IP 또는 빈 문자열",
    "final_ips": ["최종 IPv4 목록 또는 빈 목록"],
}
```

## 7. 추적 결과 출력

DNS 조회 함수 내부에서 바로 출력하지 않고, `trace_domain()`이 각 질의 단계의 정보를 `traces`에 저장한다. `print_trace()`는 이 목록을 받아 사람이 읽을 수 있는 문자열로 변환한다.

출력 함수의 동작은 다음과 같다.

1. 조회 도메인을 첫 줄에 추가한다.
2. `traces`를 순회하며 현재 질의한 DNS 서버 IP를 출력한다.
3. `next_server_ip`가 있으면 다음 DNS 서버 IP를 출력한다.
4. `next_server_ip`가 없으면 `final_ips`를 도메인 IPv4로 출력한다.
5. 완성한 문자열을 `lines` 목록에 저장한 뒤, `"\n".join(lines)`으로 한 번에 출력한다.

이렇게 DNS 질의·조회 흐름·출력의 역할을 분리했다.
